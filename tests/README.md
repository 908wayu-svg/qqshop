# ชุดทดสอบ QQSHOP

รันทั้งหมด (ไม่แตะฐานข้อมูลจริง):

```
cd tests && npm test
```

ทดสอบด้วย Firestore จำลองในหน่วยความจำ ที่ถอดกฎจาก `firestore.rules` มาทั้งชุด
แล้วรันโค้ดจริงของเว็บบน DOM จำลอง (jsdom) ทั้งในบทบาท **สมาชิกธรรมดา** และ **แอดมิน**

| ไฟล์ | ทดสอบอะไร |
|---|---|
| `t1-auth.mjs` | สมัคร/สิทธิ์สมาชิก — สิ่งที่ลูกค้าห้ามทำ |
| `t2-admin.mjs` | อนุมัติ/ปฏิเสธ ออเดอร์-เติมเงิน, ปรับเครดิต, แย่งของชิ้นสุดท้าย |
| `t3-worker.mjs` | เซิร์ฟเวอร์สั่งซื้อ (คิดราคาเอง, กันแก้ราคา, จำกัดจำนวนครั้ง) |
| `t4-angpao.mjs` | บอทรับซองอั่งเปา รวมเคสทรูมันนี่ล่ม / บันทึกไม่สำเร็จ |
| `t5-shop.mjs` | หน้าร้าน + ตะกร้า + สั่งซื้อ + XSS |
| `t6-purchases.mjs` | ประวัติการซื้อ + กล่องไอดี/รหัสผ่าน |
| `t7-admin-ui.mjs` | หน้าหลังบ้านทั้งหน้า (กด ปุ่ม ตาราง กราฟ จริงๆ) |
| `t8-wallet.mjs` | หน้าเติมเงิน ทุกช่องทาง + พร้อมเพย์ QR |
| `t9-gates.mjs` | ด่านกั้นสิทธิ์เข้าหลังบ้าน |
| `t10-load.mjs` | ข้อมูลเยอะ (สมาชิก 300 / ออเดอร์ 500 / เติมเงิน 500) ต้องไม่ค้าง |
| `t11-images.mjs` | รูปสินค้าแยกเอกสาร + โหลดตอนเลื่อนถึง |
| `t12-login.mjs` | สมัคร / เข้าสู่ระบบ / ลืมรหัสผ่าน / Google |
| `t13-overlay.mjs` | กล่องลอย: ปิดด้วย Esc, กดพื้นที่มืด, ล็อกการเลื่อน |
| `t14-offline.mjs` | เน็ตหลุด/โหลดข้อมูลไม่ได้ ต้องบอกผู้ใช้ ไม่ใช่หน้าเปล่า |
| `t15-contact.mjs` | ปุ่มติดต่อแอดมิน + กล่องช่องทางติดต่อ |
| `t16-stickers.mjs` | สติ๊กเกอร์การ์ตูนต้องไม่ทับตัวหนังสือ |
| `t17-categories.mjs` | หมวดหมู่สินค้าหน้าร้าน (แท็บกรอง) |
| `t18-categories-admin.mjs` | ช่องเลือกหมวดหมู่ในฟอร์มสินค้าหลังบ้าน |
| `t19-mobile.mjs` | จอมือถือ: ตารางแปลงเป็นการ์ด + data-label ครบ |

## ยิงจริงกับ production

```
node live-rules-check.mjs
```

ตรวจว่ากฎที่ deploy ไปแล้วบังคับใช้จริง และ index ของประวัติลูกค้าพร้อมใช้งาน
สร้างบัญชีสมาชิกทดสอบชั่วคราว → ตรวจ → **ลบบัญชีและเอกสารทุกอย่างทิ้งอัตโนมัติ**

`fake/store.mjs` คือกฎความปลอดภัยฉบับถอดความ — **ถ้าแก้ `firestore.rules` ต้องแก้ไฟล์นี้ให้ตรงกันด้วย**

## ดูหน้าจอมือถือของจริง

jsdom ไม่คำนวณ layout ให้ ถ้าอยากเห็นว่า CSS พังตรงไหนบนจอแคบ ให้ดัมป์ HTML ที่ render แล้ว
ออกมาเปิดใน Chrome จริง:

```
node dump-dom.mjs admin     dump-admin.html
node dump-dom.mjs purchases dump-purchases.html
```

ไฟล์ที่ได้จะชี้ CSS/รูปกลับไปที่ `http://localhost:8231` (เสิร์ฟโฟลเดอร์โปรเจกต์ค้างไว้ก่อน)
แล้วเปิดในกรอบ iframe กว้าง 320-390px เพื่อวัดว่ามีอะไรล้นขอบจอไหม
